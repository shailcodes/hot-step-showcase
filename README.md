# Hot Step Showcase

A single-file HTML/CSS/JS product hero card for a sneaker, with three colour variants, a Before/After wireframe toggle, and a petal-and-shoe transition animation.



## Features
- 3 colour variants (orange, green, purple) with animated shoe swap
- Before / After wireframe toggle
- Size picker, quantity stepper, Buy Now
- Responsive: desktop, phone, and 9:16 reel layout
- No build step. One `index.html`, no dependencies except the Inter font from Google Fonts

## Customise
Open `index.html` and edit the `CONFIG` object (brand, model, price, logo).
